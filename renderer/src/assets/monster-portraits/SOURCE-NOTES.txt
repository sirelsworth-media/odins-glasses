These PNG files are newly generated bestiary illustrations for Odin’s Glasses. Original game sprites are not included in this directory or in the packaged app.

Reference workflow:
- Monster identity, ID and level selection: the application's RagnaDex-based monster data.
- Visual recognition reference: the corresponding RO Zero DB/TWROZ sprite for each monster ID, viewed individually on 2026-09-02.
- Each reference was used only to identify body plan, important silhouette traits and established color identity.
- Each final portrait was generated as a new painterly illustration with a fresh pose and new rendering. It was then converted to a transparent 128 x 128 PNG.
- This workflow reduces direct reuse of copyrighted pixels, but it is not a legal clearance or a guarantee that a rights holder cannot object to a recognizable derivative depiction.

Shared prompt template:
"Create a new original hand-painted portrait of the depicted monster for a compact fantasy bestiary icon. Preserve the recognizable species/body plan and key palette from the reference, but invent a fresh pose and original rendering. One complete subject, centered, transparent background, no scenery, frame, text, logo, watermark, copied pixels, copied outline or pixel art."
