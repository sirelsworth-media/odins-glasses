# Odin’s Glasses 1.31.1

This maintenance release updates the public presentation and improves the Nocturne theme.

## Changes

- Replaces the outdated README screenshot with the Odin’s Glasses interface.
- Adds a direct README link to the latest Windows downloads.
- Fixes low-contrast text and controls across all nine Nocturne views.
- Adds an automated WCAG 2 AA contrast audit to the desktop UI test.
- Prevents and removes temporary Windows spell-check folders created during UI tests.

The Windows installer and portable build are unsigned and may trigger a Microsoft SmartScreen warning.
