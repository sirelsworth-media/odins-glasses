Modified by Odin’s Glasses on 2026-09-04:
Extracted monster IDs, Aegis names and baseline behavior from Renewal mob_db.yml.
Resolved AI types using mob_db_mode_list.txt and applied explicit behavior overrides.
Excluded HP, EXP, drops, stats, class/immunity flags and skill-dependent mode changes.
Unknown AI types are omitted. Global behavior is NOT verified.

The editable derived data (behavior.json), complete upstream input files, license
and conversion script are included here. Upstream revision:
e985006171d2eb320ee512a653f4c83aea3d81b6
https://github.com/rathena/rathena/tree/e985006171d2eb320ee512a653f4c83aea3d81b6

Rebuild in this folder with Node.js and js-yaml 4.1.1 installed:
node import-rathena-behavior.cjs --offline
No upstream network access is needed for an offline rebuild.
