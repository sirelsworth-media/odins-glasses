# Asset licensing and provenance

The GPL-3.0-or-later license covers Odin’s Glasses's source code. Assets have
separate provenance and should not be assumed to have the same legal status.

## Project-created illustrations

The monster portraits, item illustrations, category icons, interface graphics,
and Odin’s Glasses application icon were created for this project, including with
generative image tools and subsequent selection, resizing, and integration.
Original Ragnarok sprites are not shipped in the current application.

To the extent that the Odin’s Glasses contributors hold transferable rights in
these project-created assets, they are offered under CC BY 4.0 with attribution
to “Odin’s Glasses contributors”:

https://creativecommons.org/licenses/by/4.0/

This statement cannot grant rights in third-party names, trademarks, character
designs, or other underlying material. Some illustrations were developed after
reviewing the recognizable identity of game creatures or items. Anyone planning
commercial publication or substantial reuse should perform an independent
rights review.

## rAthena and RagnaDex data

rAthena source material and editable derivatives remain GPL-3.0-or-later.
RagnaDex data is obtained at runtime under the attribution condition described
in `THIRD_PARTY_NOTICES.md`; it is not relicensed as original Odin’s Glasses art.

## Excluded working material

`previews/`, development contact sheets, generated-image working folders, old
release directories, and local source-reference downloads are not part of the
public source release unless a release manifest explicitly includes them.

## Crafting illustration completion – 2026-09-11

28 missing recipe-output illustrations were generated using original item images
as visual references and the existing Odin’s Glasses illustrations as style guides.
They are new hand-painted-style renderings; source sprite files are not shipped.
Item IDs, prompts and reference links are recorded in
scripts/crafting-generated-20260911.json. In-app derivatives are 128x128 PNGs.
The existing third-party underlying-design caveat continues to apply.
